Lecture du graphique de comparaison

Chaque barre représente la proportion de politiciens Wikidata du parti qui ont été impliqués dans au moins une affaire, cumulativement jusqu'à l'année sélectionnée avec le curseur. Le label à droite de la barre indique le nombre brut (X mis en cause / Y total documentés).

Le dénominateur est le nombre total de politiciens français documentés dans Wikidata pour ce parti — indépendant de Crapulopédia. Ce n'est pas le nombre de membres au sens large, mais les personnes ayant exercé une fonction politique documentée.

Biais connus

  1. Crapulopédia n'est pas exhaustive. Elle recense les affaires notables documentées sur Wikipédia. Les infractions non médiatisées sont absentes.
  2. Biais de notoriété. Les politiciens plus connus ont plus de chances d'être documentés.
  3. Biais temporel. Les affaires récentes sont mieux couvertes que les affaires anciennes.
  4. Dénominateur Wikidata incomplet. Wikidata ne documente pas tous les politiciens — les petits partis et les périodes anciennes sont lacunaires.
  5. Matching imparfait. Correspondance Crapulopédia ↔ AN/Sénat par normalisation de noms — des erreurs sont possibles.
  6. Groupes ≠ partis. Les groupes parlementaires regroupent parfois plusieurs partis.
  7. ACP et clustering. Groupes mathématiques, aucune signification politique.
  8. Petits effectifs. Partis avec < 5 affaires : statistiques peu fiables.
