Taux normalisés par parti

Les taux sont calculés en rapportant le nombre d'affaires au nombre de politiciens documentés dans chaque source. Le Taux Wikidata est le plus rigoureux (dénominateur large, indépendant de la base Crapulopédia). Le Taux Crapulopédia utilise les politiciens distincts ayant au moins une affaire comme proxy. La couleur des barres reflète la position sur le spectre gauche–droite.

Évolution temporelle — Taux cumulatifs normalisés

Pour chaque parti, le taux cumulatif représente : nombre cumulé d'affaires jusqu'à l'année t divisé par le nombre cumulatif de membres documentés dans Wikidata jusqu'à t (×1 000). Cette approche évite le biais de taille des partis et prend en compte leur durée d'existence.
Le taux Crapulopédia utilise les politiciens de la base crapulopédia comme dénominateur alternatif.

Analyses statistiques formelles

Ces outils permettent d'explorer et de tester des hypothèses sur les données. Rappel : corrélation ≠ causalité. Toutes les analyses sont exploratoires.

Tests d'hypothèses formels

Tests non-paramétriques sur les métriques normalisées des partis. Ces tests ne supposent pas de distribution normale et sont adaptés aux petits échantillons.

⚠ Le niveau de significativité retenu est α = 0,05. Pour des comparaisons multiples, le seuil devrait être corrigé (Bonferroni). Ces tests opèrent sur ≤ 39 partis — les résultats doivent être interprétés avec prudence.

ACP — Biplot (scores + contributions)

Réduction dimensionnelle sur les métriques normalisées. Les points représentent les partis projetés sur PC1/PC2. Les flèches rouges montrent la contribution et le sens de chaque variable.

⚠ Les axes PC1 et PC2 sont des combinaisons linéaires des variables d'entrée. Ils ne correspondent à aucune dimension politique préétablie.

Métriques normalisées

MétriqueFormuleInterprétation
Taux Wikidata nb_affaires / nb_politiciens_wikidata × 1 000 Affaires pour 1 000 politiciens français documentés dans Wikidata (source externe, indépendante)
Taux Crapulopédia nb_affaires / nb_politiciens_crapu × 100 Affaires pour 100 politiciens distincts dans la base (biais : dénominateur auto-référentiel)

Biais connus et limites

  1. Crapulopédia n'est pas exhaustive. Elle recense les affaires notables documentées sur Wikipédia. Les infractions non médiatisées ou non documentées sont absentes.
  2. Biais de notoriété. Les politiciens plus connus ont plus de chances d'être documentés.
  3. Biais temporel. Les affaires récentes sont mieux couvertes que les affaires anciennes.
  4. Dénominateur Wikidata incomplet. Wikidata ne documente pas tous les politiciens — les données des petits partis ou des périodes anciennes sont lacunaires.
  5. Matching imparfait. La correspondance entre Crapulopédia (Wikidata IDs) et les données officielles AN/Sénat (noms) se fait par normalisation de noms — des erreurs sont possibles.
  6. Groupes parlementaires ≠ partis. Les groupes à l'AN regroupent parfois plusieurs partis distincts.
  7. ACP et clustering sans signification politique. Ces méthodes créent des groupes mathématiques sans intention éditoriale.
  8. Petits effectifs. Pour les partis avec < 5 affaires, les statistiques sont très sensibles aux valeurs individuelles.
  9. Proxy d'âge de début de carrière. La correction par carrière-année suppose un début de carrière à 30 ans — hypothèse simplificatrice.
