Outils d'analyse statistique

Ces outils permettent d'explorer les données sous plusieurs angles statistiques. Rappel : corrélation ne signifie pas causalité. Ces analyses sont exploratoires.

Analyse en Composantes Principales (ACP)

Réduction dimensionnelle sur les variables : nombre d'affaires, score de gravité moyen, position sur le spectre politique, nombre de politiciens distincts. Les axes PC1 et PC2 n'ont pas de signification politique intrinsèque.

⚠ L'ACP est une méthode mathématique de réduction de dimension. Les axes résultants sont des combinaisons linéaires des variables d'entrée et ne correspondent à aucun concept politique préétabli.

Classification automatique (k-means)

Regroupement des partis selon leurs similarités statistiques. Le nombre de groupes optimal est suggéré par la méthode du coude.

⚠ Le clustering est un algorithme mathématique. Les groupes obtenus n'ont aucune signification politique et ne reflètent aucun jugement éditorial. Changer le nombre de clusters peut modifier radicalement les résultats.

Matrice de corrélations (Pearson)

Coefficients de corrélation entre les variables numériques. Les p-values sont affichées pour évaluer la significativité statistique.

⚠ Une corrélation, même forte et significative, ne prouve pas de lien de causalité. Les tailles d'échantillon sont faibles pour certains partis — interpréter avec précaution.

Régression linéaire

Modèle linéaire simple : position sur le spectre politique (X) → nombre d'affaires (Y). Droite de régression avec intervalle de confiance à 95 %.

⚠ Ce modèle est exploratoire. L'effectif par parti est faible. Un R² élevé ne garantit pas que la relation est politiquement interprétable.

Méthodologie, sources et biais

⚠ Avertissement général
Ce site est un outil d'exploration de données ouvertes. Il n'exprime aucune opinion politique et ne prétend pas à l'exhaustivité. Les données présentées sont issues de sources publiques et peuvent comporter des erreurs ou des omissions. Tout résultat doit être interprété avec précaution et dans son contexte.

Biais connus et limites

  1. Crapulopédia n'est pas exhaustive. Elle recense les affaires notables documentées sur Wikipédia. Les infractions moins médiatisées ou non documentées en ligne sont absentes. Les partis avec plus de couverture médiatique peuvent donc apparaître surreprésentés.
  2. Biais de notoriété. Les politiciens plus connus ont davantage de chances d'être documentés et donc d'apparaître dans la base. Un élu local peu médiatisé avec une condamnation n'y figurera probablement pas.
  3. Biais temporel. Les affaires récentes sont mieux documentées que les affaires anciennes. La comparaison inter-temporelle doit être faite avec prudence.
  4. Pas de dénominateur pour l'historique. Pour les partis historiques dissous, il est impossible de calculer un taux (nombre total de membres inconnu). Seules les données brutes sont présentées pour cette période.
  5. Matching imparfait entre sources. Le croisement entre Crapulopédia (IDs Wikidata) et les données officielles AN/Sénat (noms) est réalisé par correspondance de noms normalisés. Des erreurs de matching sont possibles (homonymes, variations d'orthographe).
  6. Groupes parlementaires ≠ partis. Les groupes parlementaires (Rassemblement National, Socialistes et apparentés, etc.) regroupent parfois plusieurs partis distincts. La correspondance avec les partis de Crapulopédia peut être imprécise.
  7. ACP et clustering sans signification politique intrinsèque. Ces méthodes mathématiques créent des groupes à partir de similarités statistiques, sans aucune intention éditoriale.
  8. Échantillons petits pour certains partis. Les partis avec moins de 5–10 affaires ont des statistiques très sensibles aux valeurs individuelles. Les intervalles de confiance sont larges.

Score de gravité

Le score de gravité est calculé par Crapulopédia à partir des peines prononcées : prison ferme, prison avec sursis, amende ferme, amende avec sursis, inéligibilité. Un score de 0 indique une affaire sans peine documentée (ex. : relaxe, classement). Un score élevé correspond à des peines lourdes.

Statuts des verdicts

  • Définitif : jugement définitif (toutes voies de recours épuisées)
  • En appel : décision de première instance, appel en cours ou possible
  • Cassation : affaire devant la Cour de cassation
  • Inconnu : statut non renseigné dans la base
